# Azure DevOps Pipeline

> End-to-end CI/CD pipeline built using Azure DevOps for automated application deployment.

## Overview

This project demonstrates how to build an enterprise-grade CI/CD pipeline using Azure DevOps. The pipeline automates application build, testing, infrastructure provisioning, and deployment.

## Features

- Azure DevOps YAML Pipelines
- Automated Build
- Continuous Integration
- Continuous Deployment
- Infrastructure as Code
- Pipeline Variables
- Secure Secrets Management
- Multi-stage Pipeline

## Tech Stack

- Azure DevOps
- YAML
- Azure CLI
- Terraform
- Git
- PowerShell
